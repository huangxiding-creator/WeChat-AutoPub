# WeChat-AutoPub · 微信公众号自动发布助手

Windows 桌面级自动化工具：扫码登录公众号后台后，**自动发布草稿箱文章 + 发表记录贴图**，多账号循环，每日定时运行，全程拟人节奏与企微通知。

> **安全红线（代码级强制）**：本工具**永不执行删除、编辑**动作，只做"发表现有草稿"。所有点击/导航均过 [src/browser/safety.py](src/browser/safety.py) 安全守卫，危险按钮文本直接抛异常终止。

---

## 功能特性

| 能力 | 说明 |
|------|------|
| 📝 草稿自动发布 | 发布草稿箱最近 N 天（默认 3 天）的文章与贴图：贴图不限日期全发，文章按天数窗口过滤；篇间随机间隔 2~3 分钟（贴图 20~50 秒） |
| 🖼️ 贴图自动发布 | 发表记录 →「已自动生成贴图草稿」→「去查看」→ 智能等待生成（可见性判据，最长 10 分钟）→「发表」，翻最近 5 页 |
| 👥 多账号循环 | 每账号独立浏览器 Profile + 固定调试端口，登出零次——切换账号=切换浏览器 |
| 🤖 拟人节奏 | 每步操作后随机停 1~3 秒；篇间 3~5 分钟；单账号单日发布数熔断；连续失败熔断 |
| ⏰ 定时运行 | Windows 任务计划每天 09:00~12:00 **窗口内随机时刻**启动（拟人化），电脑重启任务不丢，错过开机自动补跑；单实例锁防双开 |
| 📢 企微通知 | 扫码提醒、每篇发布结果、失败原因、每日汇总推送到企业微信群机器人 |
| 📸 全程存证 | 发布前后截图 + 弹窗 HTML 存档，事后可追溯 |
| 📡 接口侦察 | 内置 CGI 抓包（请求+关键响应体落盘），为逆向复刻 API 积累数据 |
| 🖥️ GUI / CLI | PySide6 桌面界面 + 命令行双入口 |

## 实战架构（趟过的坑）

- **浏览器守护进程模式**：Chrome 以独立子进程常驻（DETACHED + 固定端口），Python 重启/崩溃**不碰浏览器**，登录态跨运行存活，把扫码次数压到最低
- **僵尸 tab 清场**：旧会话页面携带过期 token 持续轮询会被平台判定冲突掐死会话——每次登录前自动关闭所有遗留公众号 tab
- **可见性三重陷阱防御**：`display:none` 的 Vue 模板节点、`opacity` 渐显的悬停工具栏、5~25 秒才弹的慢加载弹窗——全部以**计算样式 + 尺寸实测**判定，仅凭选择器命中一律视为误报
- **双屏确认链（真实点击+安静期判据）**：确认弹窗分两屏（屏1 发表 → 屏2 发表/继续发表——无通知次数账号是「继续发表」）；JS 合成点击对 Vue 弹窗可能无效，用 CDP 真实元素点击；换屏有 2~5 秒空窗期，完成判据=弹窗关闭后连续 10 秒无新弹窗
- **无通知次数也能发**：群发通知开关默认关闭时直接发表=内容上公众号主页+可获平台推荐，不受每月通知次数限制
- **金标准验证**：发布成功以"草稿从草稿箱消失 + 发表记录可查"为准；页面瞬时报错不触发重发（防重复发布）
- **贴图「去查看」是单次消费制**：点一次入口即从发表记录消失，消费后服务端贴图数据同步销毁（URL 直构编辑器永久转圈、接口重放报参数错误——三条恢复路全部实证死局）。所以贴图触发必须**等到真生成完再保存**，绝不在加载中关 tab 或点保存
- **「草稿加载中」toast 是常驻 DOM 隐藏模板**：子串匹配 HTML=永久假阳性（白等8分钟）、截断扫描=永久看不见（toast 挂 48 万字符页面的 body 末尾）。唯一可靠判据=计算样式可见性（`_a2p_toast_visible`）
- **贴图保存防静默失败**：`isNew=1` 变体编辑器不自动落草稿箱，「保存为草稿」需 CDP 真实点击且必须等生成完成——点在加载中=无 POST 无报错的静默失败

## 快速开始

### 环境

- Windows 10/11 + Python 3.11+
- Chrome / Edge 浏览器
- （可选）企业微信群机器人 Webhook

### 安装

```bash
git clone https://github.com/huangxiding-creator/WeChat-AutoPub.git
cd WeChat-AutoPub
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy config.example.ini config.ini
```

### 配置（config.ini，全部中文键名）

```ini
[账号]
单账号单日最大发布数 = 20
登录等待扫码超时分钟 = 30
开启新账号扫码窗口 = 否      ; 多公众号时改「是」

[草稿]
发布最近天数 = 3
每篇间隔最小秒 = 120
每篇间隔最大秒 = 180

[贴图]
翻页数 = 5
草稿加载等待最长分钟 = 10

[定时]
启用 = 是
运行时间 = 09:00
; 每天 09:00~12:00 窗口内随机时刻启动（拟人化，避开固定指纹）
最晚运行时间 = 12:00
错过补跑 = 是                ; 9点没开机，开机后立即补跑

[通知]
企微Webhook = https://qyapi.weixin.qq.com/...
通知开关 = 是
```

### 运行

```bash
python run.py --mode run          # 立即运行完整流程（多账号循环）
python run.py --mode auto --window 09:00-12:00  # 窗口内随机时刻启动
python run.py --install-schedule  # 安装每日定时任务：09:00 触发、窗口内随机启动（一次即可）
python run.py --recon             # 侦察模式：dump 页面 HTML 供选择器调试
python main.py                    # GUI 界面
```

首次运行会拉起浏览器显示公众号登录二维码，用微信扫码（企微同步提醒）；之后 cookie 长效复用，多数日子免扫码。

## 项目结构

```
src/
├── browser/          # DrissionPage 浏览器自动化层
│   ├── session.py    #   会话生命周期、稳健点击、断线重连、僵尸tab清场
│   ├── safety.py     #   安全守卫（红线：禁删禁改）
│   ├── login.py      #   扫码登录 + cookie 复用 + 昵称提取
│   ├── nav.py        #   菜单导航、弹窗处理、可见性点击原语
│   ├── drafts.py     #   草稿解析 → 双「发表」确认链 → 金标准验证
│   ├── picposts.py   #   贴图发布（去查看 → 等生成 → 发表）
│   ├── capture.py    #   CGI 抓包侦察（API 复刻数据源）
│   └── selectors.py  #   DOM 选择器集中管理（改版只改这里）
├── core/
│   ├── orchestrator.py  # 多账号循环编排、熔断
│   └── state.py         # 发布台账（防重复发布）
├── scheduler/        # Windows 任务计划（每天 9~12 点随机窗口，重启存活+错过补跑）
├── gui/              # PySide6 桌面界面
├── notify/           # 企微群机器人通知
├── llm/              # 智谱 GLM 免费模型接入
└── api/              # 公众号 CGI 直连客户端（抓包数据复刻）
tests/                # 33 项单元测试
```

## 风控与合规说明

- 自动化操作公众号后台存在被平台风控的可能。本工具通过**拟人节奏 + 独立浏览器指纹 + 低频操作**降低风险，但不作任何保证
- 工具只发布**你自己创建的草稿内容**，不生成、不修改、不删除任何内容
- 仅供个人公众号运营效率提升与研究学习，请遵守[微信公众平台服务条款](https://mp.weixin.qq.com/cgi-bin/readtemplate?t=mp/agreement/index)
